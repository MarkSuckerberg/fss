## Hey, listen!

If you've come across this repo by any chance, wanting to get furaffinity RSS feeds, you should PROBABLY use [RSS-bridge](https://github.com/RSS-Bridge/rss-bridge) instead. It's a lot less finnicky, as well as has a *bunch* more bridges for sites that don't already have a feed.

I'll be archiving this since it broke due to the FAAPI package breaking as of 2026/4/17, and I don't really have a desire to make an entire fork of it for just this project in particular.

# FA RSS Proxy

This simple python program runs a flask server that allows you to subscribe to furaffinity accounts as if they had an official RSS feed. Currently only supports galleries.

Not proud of this code, but I wanted to learn flask.
